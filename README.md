## Short Run Instructions

### 1. Spreadsheet Analysis
*   Navigate to the `02_spreadsheet/` folder.
*   Open `spreadsheet_workbook.xlsx` to view the data cleaning, business logic formulas (High Risk/High Value flags), and pivot table summaries.
*   Refer to `spreadsheet_answers.md` for the written methodology and final metric counts.

### 2. SQL Analysis
*   Navigate to the `03_sql/` folder.
*   Review `sql_answers.md` to see the analytical queries used to extract insights on merchant performance, GMV trends, and chargeback ratios.
*   Queries can be executed against any standard SQL environment containing the transaction dataset.

### 3. Python/Colab Analysis
*   Open the `.ipynb` notebook in the `04_python/` folder.
*   Upload the raw CSV files from the `01_data/` folder when prompted.
*   Run all cells to execute the data pipeline, which includes data cleaning, risk analysis, and automated CSV exports.

### 4. Visualization
*   Open `05_visualization/dashboard_link.txt` to access the live interactive dashboard.
*   The dashboard provides a visual breakdown of GMV by region, merchant performance, and risk trends.
